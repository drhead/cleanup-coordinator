ℹ️ Instructions

Welcome! This tool coordinates cleanup projects on e621, specifically targeting duplicate uploads and unmarked post variants.

Warning: This site links directly to explicit content. If you are under 18, leave now. You are entirely responsible for what you choose to view.

Work is organized into projects built around specific search criteria. Each project presents groups of related posts as clusters that likely need attention.

To work on a cluster, open the post links and make your edits directly on e621 using your account. Always defer to specific project guidelines when available, but general rules apply:

  • Only the highest-quality version of an exact image should remain on the site. Lower-quality duplicates should be flagged.
  • Distinct variants or related posts should be linked as parent/child or grouped into a pool.
  • Check surrounding context carefully. Quality and accuracy matter far more than speed.

Claiming Batches

Claiming a batch reserves it for one hour (limit one batch per user) so others know you are working on it. Claimed batches remain viewable by everyone. Batch sizes are kept small so you can comfortably finish without hitting e621 rate limits. When you finish, click Release so others know that you are done with the batch.

Syncing Progress

All post data automatically updates via periodic background syncs. If you want your recent edits (such as tags, ratings, or relationships) reflected immediately, click the Refresh Batch button, or simply release the batch when finished.

Cluster Tools & Blacklist

Cluster cards show fully expanded tag lists and ratings so you know what you are looking at beforehand. The Copy Merged Tags button will copy all tags present in the cluster (except different artist tags). You're encouraged to use this to add more valid tags to posts, but you should make sure they actually are valid before submitting on e621.

Some discrepancies within a cluster are automatically pointed out, like mismatched artist tags or conflicting ratings on identical posts. Review these carefully, as resolving them may require updating tags or filing an alias request. The warning should be automatically cleared once it is resolved.

You can manage your blacklist in the header. It defaults to e621's standard syntax and list, collapsing any clusters containing blacklisted content. Hovering over a BLACKLISTED badge reveals the exact rule that triggered it.
